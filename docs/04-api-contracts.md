# F. REST API Contracts

Base: `/api/v1`. OpenAPI 3.1 generated by FastAPI at `/api/v1/openapi.json`; web TS client and Dart client are generated from it in CI (`openapi-typescript`, `openapi-generator dart-dio`) so clients never drift.

## 1. Conventions

| Topic | Rule |
|-------|------|
| Auth | `Authorization: Bearer <access JWT>` (15 min). Refresh via `/auth/refresh` (rotating, 30 days, reuse detection). |
| Company context | `X-Company-Id` header required on company-scoped routes; server checks user has a role in it. Owner "all companies" reports take `company_ids=` query param, each validated. |
| Pagination | `?page=1&page_size=50` (max 200) → `{items, page, page_size, total}`. Ledgers/movements/audit use cursor `?cursor=&limit=`. |
| Filtering | Explicit query params per resource (`status=APPROVED&status=ALLOCATED`, `date_from`, `date_to`, `dealer_id`, `godown_id`, `brand_id`, `q`). No generic query language. |
| Sorting | `?sort=-order_date,order_no` (whitelisted fields). |
| Decimals | JSON strings: `"qty": "25.000"`, `"amount": "125000.00"`. |
| Dates | `date` = `YYYY-MM-DD` (IST business date); timestamps ISO-8601 UTC. |
| Concurrency | Mutations on versioned resources send `version`; mismatch → `409 VERSION_CONFLICT`. |
| Idempotency | `Idempotency-Key` header **required** on: order submit/approve, payment report, dispatch confirm, POD, receipt post, transfer dispatch/receive, adjustment post, import post. Mobile sends `client_uuid` too. |
| Commands | State changes are `POST /{resource}/{id}/{action}`; `PATCH` only edits fields allowed in the current state. Status field is read-only everywhere. |
| Errors | `application/problem+json`: `{type, title, status, code, detail, errors:[{field, code, message}], request_id}` |
| Rate limits | Auth endpoints 10/min/IP+phone; general 600/min/user; connector 120/min. `429` with `Retry-After`. |
| Exports | `GET …/export?format=xlsx&<same filters>` → small: streamed file; large: `202 {job_id}` + notification with download link. |

Common error codes: `VALIDATION_ERROR, NOT_FOUND, FORBIDDEN, SCOPE_FORBIDDEN, INVALID_TRANSITION, VERSION_CONFLICT, IDEMPOTENCY_MISMATCH, STOCK_INSUFFICIENT, STOCK_CHANGED, CREDIT_HOLD, RATE_BELOW_MIN, DUPLICATE_SUSPECTED, DUPLICATE_REFERENCE, CAPACITY_EXCEEDED, TALLY_DATA_STALE, APPROVAL_REQUIRED`.

## 2. Endpoints

### Auth & users
```
POST /auth/login                {phone, password, device_id} → {access_token, refresh_token, user, companies[], permissions_by_company}
POST /auth/refresh              {refresh_token} → new pair (old one revoked; reuse → whole family revoked)
POST /auth/logout               revoke current family
POST /auth/password/forgot | /auth/password/reset
GET  /auth/me                   profile, roles per company, permissions, scopes
POST /devices                   register FCM token
GET|POST /users, GET|PATCH /users/{id}, POST /users/{id}/roles, POST /users/{id}/deactivate
GET  /roles, GET /permissions, POST|PATCH /roles/{id}
```

```http

  "version": 4,
  "allocations": [
    {"order_item_id": "0192…a", "godown_id": "NASIRPUR", "owner_id": "own-att", "qty_base": "400"},
    {"order_item_id": "0192…a", "godown_id": "UTTAM_NAGAR", "owner_id": "own-att", "qty_base": "100"}
```
